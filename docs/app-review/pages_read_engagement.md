# pages_read_engagement

## Use case
Read comments on the Page's own posts so a keyword rule can reply publicly and send a private message, the same comment-to-DM path as Instagram. Helixa reads the comment text and the commenter id. It does not boost posts or read comments on unrelated Pages.

## Screencast
1. Comment on a post published by the connected Page, using the keyword from the Facebook automation.
2. In Helixa, show the rule that matches that keyword.
3. Show the public reply on the post and the private reply in Messenger.
4. Do not react, share, or create a post during the recording.
