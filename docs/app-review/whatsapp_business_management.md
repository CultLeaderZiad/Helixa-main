# whatsapp_business_management

## Use case
Read the WhatsApp Business Account and its phone numbers so the customer can pick the number Helixa should use, and sync message templates so a flow or broadcast can send an approved template. Helixa does not register a new number by itself and does not submit a template to Meta from this recording unless you already use the template screen.

## Screencast
1. Start WhatsApp connect and show the business account and phone number that come back.
2. Save the number and show it on Connected Platforms.
3. Open the template list and show the name and status of an existing template.
4. Do not delete the WABA, register a number, or edit a display name.
