# message.list.manage

## Use case
Update conversation state that Business Messaging requires for a managed thread, including read state when an agent opens the thread in Helixa. Helixa does not delete the user's TikTok account or their other conversations.

## Screencast
1. Open an unread TikTok thread in the Helixa inbox.
2. Show the thread marked read in Helixa after the agent opens it.
3. If TikTok's UI shows the same read state, include that frame.
4. Do not delete the thread.
