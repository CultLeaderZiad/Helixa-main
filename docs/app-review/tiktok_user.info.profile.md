# user.info.profile

## Use case
Read the public profile fields TikTok returns for the business account (display name and avatar) so the workspace switcher and channel card match what the creator sees in TikTok. Helixa does not edit the profile.

## Screencast
1. Connect TikTok.
2. Show the display name or avatar Helixa stored next to the TikTok app profile.
3. Do not change the TikTok bio, avatar, or name from Helixa.
