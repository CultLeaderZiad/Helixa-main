# instagram_business_manage_comments

## Use case
Read comments on the professional account's posts and send the public reply plus the private DM the creator attached to that keyword. This is the comment-to-DM funnel. Helixa does not create posts, and it does not comment on other people's posts.

## Screencast
1. On the connected professional account, open an existing post the reviewer can comment on.
2. From a second account, comment with the keyword configured on that automation.
3. In Helixa, open the automation and show the keyword, the public reply text, and the private message.
4. Show the public reply under the comment and the DM in the commenter's inbox.
5. Show that no new media was published.
