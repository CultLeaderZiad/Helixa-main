# pages_messaging

## Use case
Send and receive Messenger conversations for the Page the customer connected. The same inbox, flows, and AI agent used for Instagram run on those Messenger threads. Helixa replies to a person who messaged the Page. It does not send a broadcast to people who have not opted in, and Messenger broadcasts are not part of this permission.

## Screencast
1. From a Facebook account, message the connected Page with a keyword.
2. Open the Helixa inbox and show the Messenger thread, labeled as Messenger.
3. Let the automation reply, then show the reply in Messenger.
4. Send one manual reply from the inbox.
5. Do not message a person who did not start the conversation.
