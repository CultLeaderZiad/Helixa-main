# pages_show_list

## Use case
List the Facebook Pages the logged-in person manages so they can pick which Page Helixa should connect. Helixa stores the chosen Page id. It does not change Page roles or create Pages.

## Screencast
1. Open Connected Platforms and start Facebook connect.
2. On the Meta consent screen, point out `pages_show_list`.
3. After redirect, show the list of Pages returned for that user.
4. Select one Page and show it saved on the connected-platforms card.
5. Do not add a person to the Page or create a Page.
